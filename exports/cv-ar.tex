\section*{الملف الشخصي}
مهندس DevOps و DevSecOps متخصص في بناء خطوط CI/CD موثوقة، تأمين مجموعات Kubernetes، وأتمتة البنية التحتية على نطاق واسع. أعمل على AWS، أنظمة Linux، والبيئات الحاوية، مع خبرة عميقة في GitLab CI/CD، Terraform، Ansible، وأكوام المراقبة.\par
\section*{المهارات التقنية}
\textbf{السحابة}: AWS (EC2, EKS, ECR, IAM, S3, VPC, Lambda)\par
\textbf{الحاويات والتنسيق}: Docker, Kubernetes, Helm, Kustomize, Istio, OPA, Kyverno\par
\textbf{CI/CD و GitOps}: GitLab CI/CD, Jenkins, ArgoCD, Flux CD, GitLab Runners\par
\textbf{البنية التحتية ككود}: Terraform, Ansible\par
\textbf{الأمان}: Trivy, GitLeaks, Semgrep, OWASP ZAP, SonarQube, Checkov, KubeLinter, Falco, HashiCorp Vault, AWS Secrets Manager\par
\textbf{المراقبة والتسجيل}: Prometheus, Grafana, Loki, Alertmanager\par
\textbf{الشبكات · البرمجة · قواعد البيانات · التخزين}: Nginx Ingress, Traefik, Cert-Manager, External-DNS, Bash, Python, PostgreSQL, MongoDB, Redis, NFS, Harbor, Nexus\par
\textbf{المحاكاة الافتراضية · أدوات الذكاء الاصطناعي}: KVM, VirtualBox, Vagrant, MCP, OpenCode, AI-assisted infra\par
\section*{الخبرة المهنية}
\cventry{مهندس DevOps و DevSecOps}{TUNISIE SOFTWARE FACTORY \& BE-SOFTILYS}{يونيو 2025 – أكتوبر 2024}
\begin{itemize}
  \item بناء خطوط GitLab CI/CD مع فحص Trivy، GitLeaks، و Semgrep. صور الحاويات الضعيفة ممنوعة قبل الانتقال
  \item نشر أمان Zero-Trust على مجموعات Kubernetes باستخدام Istio mTLS، NetworkPolicies، و OPA Gatekeeper
  \item ربط HashiCorp Vault بسياقات النشر مع التدوير الآلي للأسرار عبر External Secrets Operator
  \item إنشاء لوحات Prometheus و Grafana مع توجيه Alertmanager؛ انخفاض ملحوظ في MTTR
  \item تكوين HPA و PodDisruptionBudgets للتعامل مع ارتفاعات الحركة بدون فقدان الطلبات
  \item أتمتة توفير شهادات TLS عبر Cert-Manager لجميع موارد Ingress
  \item إجراء اختبارات تحقق شاملة للبنية التحتية بعد كل دورة توفير
  \item تطبيق بوابات أمان CI/CD مع عتبات الثغرات؛ فشل خطوط الإنتاج عند تجاوز العتبات
  \item مركزية تتبع الثغرات في DefectDojo لمتابعة الإصلاحات
  \item تصحيح مشاكل تنفيذ Kubernetes — CrashLoopBackOff، ImagePullBackOff، أخطاء الجدولة
  \item كتابة runbooks ووثائق النشر؛ الاحتفاظ بتقارير التحقق
  \item مناقشات ما قبل البيع مع عملاء محتملين حول خيارات البنية
  \item تكوين خوادم MCP للمساعدين الذكية للاستعلام عن بيانات Kubernetes و CI/CD والمراقبة
  \item إدخال المساعدين الذكية في سير العمل اليومي لتحليل السجلات، فرز الحوادث، التشخيص
  \item استخدام أدوات الذكاء الاصطناعي لتسريع تطوير Terraform و Ansible؛ أخطاء تكوين أقل
  \item قواعد حماية الفرع مع مراجعات إلزامية وفحوصات آلية لخطوط الإنتاج
  \item ربط Alertmanager بـ Jira؛ التنبيهات تولد تذاكر خدمة تلقائياً
  \item أمان سلسلة التوريد: توليد SBOM، توقيع Cosign، تتبع التبعيات
  \item نشر Falco لأمان وقت التشغيل على أحمال عمل Kubernetes
\end{itemize}
