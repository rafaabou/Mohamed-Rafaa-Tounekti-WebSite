\section*{الملف الشخصي}
مهندس \LR{DevOps} و \LR{DevSecOps} متخصص في بناء خطوط \LR{CI/CD} موثوقة، تأمين مجموعات \LR{Kubernetes}، وأتمتة البنية التحتية على نطاق واسع. أعمل على \LR{AWS}، أنظمة \LR{Linux}، والبيئات الحاوية، مع خبرة عميقة في \LR{GitLab CI/CD}، \LR{Terraform}، \LR{Ansible}، وأكوام المراقبة.\par
\section*{المهارات التقنية}
\textbf{السحابة}: \LR{AWS (EC2, EKS, ECR, IAM, S3, VPC, Lambda)}\par
\textbf{الحاويات والتنسيق}: \LR{Docker, Kubernetes, Helm, Kustomize, Istio, OPA, Kyverno}\par
\textbf{\LR{CI/CD} و \LR{GitOps}}: \LR{GitLab CI/CD, Jenkins, ArgoCD, Flux CD, GitLab Runners}\par
\textbf{البنية التحتية ككود}: \LR{Terraform, Ansible}\par
\textbf{الأمان}: \LR{Trivy, GitLeaks, Semgrep, OWASP ZAP, SonarQube, Checkov, KubeLinter, Falco, HashiCorp Vault, AWS Secrets Manager}\par
\textbf{المراقبة والتسجيل}: \LR{Prometheus, Grafana, Loki, Alertmanager}\par
\textbf{الشبكات · البرمجة · قواعد البيانات · التخزين}: \LR{Nginx Ingress, Traefik, Cert-Manager, External-DNS, Bash, Python, PostgreSQL, MongoDB, Redis, NFS, Harbor, Nexus}\par
\textbf{المحاكاة الافتراضية · أدوات الذكاء الاصطناعي}: \LR{KVM, VirtualBox, Vagrant, MCP, OpenCode, AI-assisted infra}\par
\section*{الخبرة المهنية}
\cventry{مهندس \LR{DevOps} و \LR{DevSecOps}}{\LR{TUNISIE SOFTWARE FACTORY \& BE-SOFTILYS}}{يونيو \LR{2025 –} أكتوبر \LR{2024}}
\begin{itemize}
  \item بناء خطوط \LR{GitLab CI/CD} مع فحص \LR{Trivy}، \LR{GitLeaks}، و \LR{Semgrep.} صور الحاويات الضعيفة ممنوعة قبل الانتقال
  \item نشر أمان \LR{Zero-Trust} على مجموعات \LR{Kubernetes} باستخدام \LR{Istio mTLS}، \LR{NetworkPolicies}، و \LR{OPA Gatekeeper}
  \item ربط \LR{HashiCorp Vault} بسياقات النشر مع التدوير الآلي للأسرار عبر \LR{External Secrets Operator}
  \item إنشاء لوحات \LR{Prometheus} و \LR{Grafana} مع توجيه \LR{Alertmanager}؛ انخفاض ملحوظ في \LR{MTTR}
  \item تكوين \LR{HPA} و \LR{PodDisruptionBudgets} للتعامل مع ارتفاعات الحركة بدون فقدان الطلبات
  \item أتمتة توفير شهادات \LR{TLS} عبر \LR{Cert-Manager} لجميع موارد \LR{Ingress}
  \item إجراء اختبارات تحقق شاملة للبنية التحتية بعد كل دورة توفير
  \item تطبيق بوابات أمان \LR{CI/CD} مع عتبات الثغرات؛ فشل خطوط الإنتاج عند تجاوز العتبات
  \item مركزية تتبع الثغرات في \LR{DefectDojo} لمتابعة الإصلاحات
  \item تصحيح مشاكل تنفيذ \LR{Kubernetes — CrashLoopBackOff}، \LR{ImagePullBackOff}، أخطاء الجدولة
  \item كتابة \LR{runbooks} ووثائق النشر؛ الاحتفاظ بتقارير التحقق
  \item مناقشات ما قبل البيع مع عملاء محتملين حول خيارات البنية
  \item تكوين خوادم \LR{MCP} للمساعدين الذكية للاستعلام عن بيانات \LR{Kubernetes} و \LR{CI/CD} والمراقبة
  \item إدخال المساعدين الذكية في سير العمل اليومي لتحليل السجلات، فرز الحوادث، التشخيص
  \item استخدام أدوات الذكاء الاصطناعي لتسريع تطوير \LR{Terraform} و \LR{Ansible}؛ أخطاء تكوين أقل
  \item قواعد حماية الفرع مع مراجعات إلزامية وفحوصات آلية لخطوط الإنتاج
  \item ربط \LR{Alertmanager} بـ \LR{Jira}؛ التنبيهات تولد تذاكر خدمة تلقائياً
  \item أمان سلسلة التوريد: توليد \LR{SBOM}، توقيع \LR{Cosign}، تتبع التبعيات
  \item نشر \LR{Falco} لأمان وقت التشغيل على أحمال عمل \LR{Kubernetes}
\end{itemize}

  \item أتمتة توفير الخوادم في \LR{dev}، \LR{staging}، \LR{production} مع \LR{Ansible}؛ القضاء على الانحراف اليدوي
  \item إعداد \LR{Flux CD} لبنية تحتية تعمل بـ \LR{GitOps}؛ بيئات تعريفية وقابلة للتدقيق
  \item نشر \LR{Grafana Loki} لتجميع السجلات المركزي؛ تحليل أسرع للأسباب الجذرية
  \item نشر بدون توقف باستراتيجيات \LR{blue-green} و \LR{canary} باستخدام \LR{Kustomize}
  \item تكوين \LR{Nginx Ingress Controller} مع إنهاء \LR{TLS} للتوجيه الخارجي
  \item توفير \LR{runners GitLab} ذاتية الاستضافة مع منفذ \LR{Docker}؛ انخفاض أوقات انتظار \LR{CI}
  \item توجيه \LR{Alertmanager} للحوادث إلى \LR{Slack} والبريد الإلكتروني؛ إخطار الأشخاص المناسبين في الوقت المناسب
  \item أتمتة نصوص اختبار للتحقق من حالة البنية التحتية بعد التوفير
  \item إدارة حوكمة خطوط الإنتاج وتخطيط التحول لإصدارات الإنتاج
  \item تتبع تدهور الأداء عبر سجلات النظام والتطبيق
  \item توثيق بنية البنية التحتية، إجراءات النشر، المشكلات المعروفة
  \item حماية فرع \LR{Git} مع مراجعات إلزامية وفحوصات الحالة؛ بوابات جودة قبل الدمج
\end{itemize}

  \item كتابة قواعد تنبيه \LR{Prometheus} للكشف الاستباقي؛ انخفاض الأعطال غير المخطط لها بنسبة \LR{40\%}
  \item أتمتة تحديثات التبعيات وتصحيحات الأمان عبر \LR{GitOps} على \LR{200+} تبعية
  \item إدارة صور \LR{Docker} و \LR{manifests Kubernetes} في \LR{Nexus} كمصدر وحيد للحقيقة

  \item بناء مكتبات \LR{Jenkins} مشتركة قابلة لإعادة الاستخدام لتوحيد قوالب خطوط الإنتاج
  \item إجراء اختبارات التثبيت والترقية؛ توثيق النتائج والإبلاغ عن الانحرافات
  \item مراقبة سعة التخزين ومقاييس الأداء؛ ضبط التكوينات للتوفر
  \item الاستجابة للحوادث وكتابة تقارير ما بعد الحادث مع خطوات المعالجة
  \item دمج \LR{LDAP} للمصادقة المركزية
\end{itemize}
